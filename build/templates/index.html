Evidence, not opinion

A test earns points only if something is documented using it

Every test carries an evidence label and graded sources, and is re-read every six months. Where we found no documented reader, the test is still measured and shown, but it is worth nothing and a site is never marked down for lacking it.

About this standard

An open standard, not a product

The AI Readiness Index was created by TEN7 and is published here under a license that lets anyone copy it, adapt it and build a scanner from it. It does not belong to any scanner. A score is a number you can reproduce from the text on this site.

TEN7 is the company behind the standard, and readinessindex.io is a product of TEN7: a scanner that implements it. They are linked so you can see where the standard came from, not to recommend them. Read more about how it is run.

  • TEN7The company that created the standard and maintains it with outside contributors.
